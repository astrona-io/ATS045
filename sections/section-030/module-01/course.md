# Security Observability And Evidence Quality

This module develops the reasoning needed to distinguish API audit, runtime and application security observations.

## Learning Goals

- Distinguish API audit, runtime and application security observations.
- Explain telemetry collection and retention trust boundaries.
- Relate alert quality to relevant behaviors and response ownership.
- Identify sensitive fields and evidence gaps.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.

1. Collection, Storage And Observation Limits
2. Security Signals Across Different Boundaries
3. Summary
