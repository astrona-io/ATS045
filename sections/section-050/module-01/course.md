# Certificates And Public Key Infrastructure

This module develops the reasoning needed to explain public keys, private keys and certificate authority trust.

## Learning Goals

- Explain public keys, private keys and certificate authority trust.
- Distinguish server authentication from mutual TLS.
- Relate identity names, validity and trust chains to verification.
- Describe rotation and compromise recovery for certificate-based identities.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
