# PKI

This section teaches certificates and public key infrastructure. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Certificates And Public Key Infrastructure. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Explain public keys, private keys and certificate authority trust.
- Distinguish server authentication from mutual TLS.
- Relate identity names, validity and trust chains to verification.
- Describe rotation and compromise recovery for certificate-based identities.
