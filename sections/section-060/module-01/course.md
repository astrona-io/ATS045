# Connectivity And Protected Network Paths

This module develops the reasoning needed to distinguish private reachability from authenticated authority.

## Learning Goals

- Distinguish private reachability from authenticated authority.
- Trace ingress, east-west and management connection boundaries.
- Relate segmentation and encryption to different protections.
- Identify required dependencies and controlled exceptions.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
