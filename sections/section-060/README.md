# Connectivity

This section teaches connectivity and protected network paths. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Connectivity And Protected Network Paths. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Distinguish private reachability from authenticated authority.
- Trace ingress, east-west and management connection boundaries.
- Relate segmentation and encryption to different protections.
- Identify required dependencies and controlled exceptions.
