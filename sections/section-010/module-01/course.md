# Supply Chain Trust And Verification

This module develops the reasoning needed to trace source, build, publication and deployment trust boundaries.

## Learning Goals

- Trace source, build, publication and deployment trust boundaries.
- Distinguish provenance, signatures, inventories and vulnerability findings.
- Relate admission decisions to exact artifact identity.
- Explain continued maintenance after an artifact is approved.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
