# Service Mesh Identity And Policy

This module develops the reasoning needed to distinguish encrypted transport, peer authentication and authorization.

## Learning Goals

- Distinguish encrypted transport, peer authentication and authorization.
- Explain where mesh components implement communication policy.
- Relate certificate rotation and hop boundaries to trust.
- Identify residual application and retry requirements.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
