# Welcome To The Course

This course is for learners preparing for the Kubernetes and Cloud Native Associate (KCSA) examination. It covers Platform Security, worth 16% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations build the reasoning needed to choose an answer and explain why the alternatives do not fit.

At the end, you can explain and compare the concepts in Supply Chain Security, Image Repository, Observability, Service Mesh, public key infrastructure (PKI), Connectivity, Admission Control. Technical terms and acronyms are defined when they appear. Examples use ordinary applications; names such as `scout` and `probe` identify workloads rather than changing the technical meaning.

Each section begins with an introduction and learning outcomes. Each section has one module with a short landing page, three deep-dive parts and a summary. The landing page starts a playground: a clean Kubernetes cluster on your own machine, with no task and no grading. A graded lab then asks you to apply what you read, and a capstone lab at the end of each section combines it. Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. Then run the command and compare.

The examination itself is multiple choice, so the hands-on work is there to make the mechanisms concrete. After each section, a knowledge check with original practice questions gives answer feedback. A final knowledge check closes the domain. These questions are independently written and are not copied from the examination.
