# Repository Access And Artifact Retention

This module develops the reasoning needed to distinguish mutable references from content-addressed artifact identity.

## Learning Goals

- Distinguish mutable references from content-addressed artifact identity.
- Compare repository push, pull and administrative privileges.
- Identify sensitive build layers and retained artifact copies.
- Relate publication integrity and credential rotation to deployment trust.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
